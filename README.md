### Technologies Used =>
* Project Name: dynamic-website
* Framework : Next.js (React)
* Styling : TailwindCss 
* Deplyment: Netlify


### Features (Minimum -5)

1. Dynamic Workout cards : Displays 12 dynamic fitness and workout cards fetched directly from API.

1. Detailed View Page: Clicking on any card opens a dedicated details page with comprehensive information about that specific workout.

3. Add to Today's Plan: Users can add desired workouts directly to their "Today's Plan" section with a single click.

4. Save for Later (Saved Items): A dedicated "Save" button allows users to bookmark routines into a separate saved list.

5. Remove Functionality: Full control to remove items easily from both the "Plan" and "Saved" sections whenever needed,.
